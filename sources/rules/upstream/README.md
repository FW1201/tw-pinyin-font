# 上游讀音資料

| 檔案 | 來源 | 授權 |
|------|------|------|
| `shendingbiao_1999.csv` | 教育部《國語一字多音審訂表》1999 年公告版；CSV 由 g0v/moedict-data-csld 整理 | 政府公告；CSV 編排以 CC0 釋出 |
| `shendingbiao_2012.csv` | 教育部《國語一字多音審訂表》2012 年公告初稿；同上 | 同上 |
| `cns11643/CNS_phonetic.txt`、`cns11643/CNS2UNICODE_*.txt` | 全字庫 CNS11643 開放資料（Properties.zip、MapingTables.zip，版本見 `cns11643/release.txt`） | 使用者可擇一：政府資料開放授權條款第 1 版／**OFL 1.1**（本專案選用 OFL 1.1） |

不使用任何大陸審音資料（Unihan kMandarin、普通話異讀詞審音表等）。

出處：
- https://github.com/g0v/moedict-data-csld
- https://data.gov.tw/dataset/5961 （全字庫 CNS11643 中文標準交換碼全字庫）
